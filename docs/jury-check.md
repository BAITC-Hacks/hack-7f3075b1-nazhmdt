# Проверка Career Quest жюри

## Запуск

Ключи для базовой проверки не нужны.

```bash
git clone https://github.com/BAITC-Hacks/hack-7f3075b1-nazhmdt.git
cd hack-7f3075b1-nazhmdt
python3 -m app.server
```

Откройте `http://127.0.0.1:8000/`.

## Основной сценарий

1. Введите код сотрудника `E0002`.
2. Откройте раздел **Развитие**.
3. Посмотрите персональную рекомендацию.
4. Откройте AI-агента и нажмите **С чего начать развитие?**.
5. Задайте свой вопрос, например: `Как мне подготовиться к следующему уровню?`.
6. Откройте демо-курс или тест.
7. Завершите активность и убедитесь, что начислены Coins.
8. Перейдите в **Coins** и **Профиль**.
9. Переключите язык, тему и уведомления в настройках.

## Что проверяется

- сотрудник видит только собственный профиль;
- рекомендации зависят от роли, цели и навыковых разрывов;
- курс, тест и задание открываются и завершаются;
- Coins начисляются после выполнения;
- AI-агент объясняет интерфейс и предлагает следующий шаг;
- без OpenAI-ключа работает автономный контекстный режим.

## Реальный ответ OpenAI

Если нужно проверить подключение модели, ключ задаётся только на компьютере жюри перед запуском сервера:

```bash
export OPENAI_API_KEY="ключ"
export OPENAI_MODEL="gpt-4o-mini"
python3 -m app.server
```

Ключ не нужно отправлять команде и нельзя сохранять в репозитории. Если ключ не задан, это не блокирует проверку продукта.

## Если доступен только один HTML-файл

Можно открыть `career-quest-standalone.html` напрямую в браузере или загрузить его на статический хостинг. В этом режиме доступны интерфейс, демо-данные, курсы, тесты, Coins и автономный AI-агент. Реальный OpenAI-ключ в HTML-файл добавлять нельзя.
