# Отдельный HR-сайт Career Quest

HR-панель находится в папке `hr_dashboard/` и не изменяет employee-сайт. Она запускается отдельным процессом и получает сводку из того же синтетического датасета.

## Запуск

Сначала запустите employee-сервер в одном окне терминала:

```bash
python3 -m app.server
```

Затем во втором окне терминала из корня репозитория запустите отдельный HR-сервер:

```bash
python3 -m hr_dashboard.server
```

Откройте `http://127.0.0.1:8010/` и введите демо-код:

```text
HR-DEMO-2026
```

Employee-сайт при этом продолжает работать отдельно на `http://127.0.0.1:8000/`. HR-панель запрашивает данные у этого же процесса, поэтому изменения прогресса видны после автообновления.

## Что видит HR

- количество сотрудников и средний прогресс;
- сотрудников без ближайшего шага;
- завершённые активности;
- прогресс и карьерную цель каждого сотрудника;
- сигналы «нужен разбор»;
- навыки с наибольшим разрывом;
- распределение статусов участия;
- поиск по имени и роли;
- фильтр по подразделению.
- клик по любой строке сотрудника открывает подробную карточку;
- в карточке доступны прогресс, цель, Coins, стаж, навыковые разрывы, рекомендации и последняя активность.

Панель обновляет данные каждые 15 секунд и имеет ручную кнопку обновления. В текущем MVP данные синтетические, а состояние выполнения хранится в памяти процесса.
