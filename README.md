## 2. Краткое описание

Сотрудник получает разрозненные HR-активности и не видит связи между ними и карьерным ростом. Career Quest должен связать профиль, историю участия, требования следующего грейда и каталог активностей в объяснимую траекторию развития. Основные пользователи — сотрудники со стажем 1–5 лет и HR.

## 3. Что реализовано

Подготовлены правила работы с репозиторием в `AGENTS.md`, исключения локальных секретов и временных файлов в `.gitignore`, а также [анализ кейса и план MVP](docs/case-1-analysis.md). Пользовательские функции пока не реализованы.

## 4. Как работает решение

Планируемый сценарий: загрузить JSON/CSV → открыть профиль сотрудника → рассчитать разрывы до цели → получить 1–3 шага с объяснением по нескольким факторам → отметить активность выполненной → увидеть обновлённые навыки и траекторию. HR получает отдельный агрегированный срез.

## 5. Технологии
