# hack-7f3075b1-nazhmdt

Репозиторий команды HackAlem AI для участника `nazhmdt`.

**Выбран кейс 1: Career Quest — AI-навигатор развития сотрудника.** Реализовано ядро загрузки данных и объяснимого подбора следующих активностей. Веб-интерфейс будет следующим этапом.

## 1. Название проекта

Рабочее название решения — `Career Quest`.

## 2. Краткое описание

Сотрудник получает разрозненные HR-активности и не видит связи между ними и карьерным ростом. Career Quest должен связать профиль, историю участия, требования следующего грейда и каталог активностей в объяснимую траекторию развития. Основные пользователи — сотрудники со стажем 1–5 лет и HR.

## 3. Что реализовано

Подготовлены исключения локальных секретов и временных файлов в `.gitignore`, [анализ кейса и план MVP](docs/case-1-analysis.md), загрузчик датасета, расчёт gaps, фильтрация активностей, ранжирование рекомендаций и тесты ядра.

## 4. Как работает решение

Текущий сценарий ядра: загрузить JSON/CSV → выбрать сотрудника → определить цель → рассчитать разрывы до цели → отфильтровать активности по роли, грейду, prerequisites и истории → получить до трёх следующих шагов с доказательствами. Интерфейс и обновление прогресса будут добавлены следующим этапом.

## 5. Технологии

Для ведения проекта используются Git, GitHub и AI-агент Codex. Текущий этап написан на Python без внешних зависимостей. Планируемый веб-слой — FastAPI, Jinja2, CSS/JavaScript; AI-модель будет добавлена для формулировки объяснений поверх рассчитанных фактов.

## 6. Архитектура проекта

В репозитории находятся:

- `README.md` — описание текущего состояния проекта.
- `.gitignore` — исключения для локальных секретов и генерируемых файлов.
- `app/data_loader.py` — загрузка и проверка JSON/CSV.
- `app/recommendations.py` — цели, gaps, фильтры и ranking рекомендаций.
- `data/career_quest_dataset/` — синтетический стартовый датасет.
- `tests/` — проверки загрузки и recommendation engine.
- `scripts/demo_recommendations.py` — воспроизводимый пример для трёх профилей.

Подробный план архитектуры находится в [анализе кейса](docs/case-1-analysis.md). Компоненты приложения пока отсутствуют.

## 7. Установка и запуск

Для получения исходников необходимы Git и доступ к приватному репозиторию команды:

```bash
git clone https://github.com/BAITC-Hacks/hack-7f3075b1-nazhmdt.git
cd hack-7f3075b1-nazhmdt
```

Внешние зависимости для текущего ядра не нужны. Из корня репозитория выполните:

```bash
python3 -m unittest discover -s tests -v
python3 scripts/demo_recommendations.py
```

API-ключи нельзя добавлять в репозиторий.

## 8. Как проверить решение

Проверочный сценарий использует профили `E0001`, `E0002` и `E0028`. Тесты проверяют количество и связи данных, выбор цели, расчёт gaps, отсутствие обязательных и уже завершённых активностей в рекомендациях.

## 9. Данные и интеграции

В репозитории используется синтетический датасет Career Quest: 200 профилей, 40 активностей, 60 навыков и 2 743 записи истории. Внешние интеграции пока не подключены.

## 10. Ограничения

- Веб-интерфейс, HR-view и обновление прогресса пока не реализованы.
- LLM-слой объяснения пока не подключён; ядро формирует структурированные основания рекомендации.
- Состояние выполнения активности пока не сохраняется через API.
