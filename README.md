# hack-7f3075b1-nazhmdt

Репозиторий команды HackAlem AI для участника `nazhmdt`.

**Выбран кейс 1: Career Quest — AI-навигатор развития сотрудника.** Зафиксированы анализ требований и продуктовый контракт; приложение ещё не реализовано.

## 1. Название проекта

Рабочее название решения — `Career Quest`.

## 2. Краткое описание

Сотрудник получает разрозненные HR-активности и не видит связи между ними и карьерным ростом. Career Quest должен связать профиль, историю участия, требования следующего грейда и каталог активностей в объяснимую траекторию развития. Основные пользователи — сотрудники со стажем 1–5 лет и HR.

## 3. Что реализовано

Подготовлены исключения локальных секретов и временных файлов в `.gitignore`, [анализ кейса и план MVP](docs/case-1-analysis.md), [продуктовый контракт](docs/product-decisions.md) и [карта AI-решений и методов](docs/ai-decisions.md). Пользовательские функции пока не реализованы.

## 4. Как работает решение

Планируемый сценарий: загрузить JSON/CSV → открыть профиль сотрудника → рассчитать разрывы до цели → получить 1–3 шага с объяснением по нескольким факторам → отметить активность выполненной → увидеть обновлённые навыки и траекторию. HR получает отдельный агрегированный срез.

## 5. Технологии

Для ведения проекта используются Git, GitHub и AI-агент Codex. Планируемый стек MVP: Python/FastAPI, Jinja2, CSS/JavaScript и AI-модель для формулировки объяснений. Точный стек будет подтверждён после реализации и проверки.
