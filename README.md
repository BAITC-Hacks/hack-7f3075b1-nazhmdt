# hack-7f3075b1-nazhmdt

Репозиторий команды HackAlem AI для участника `nazhmdt`.

**Выбран кейс 1: Career Quest — AI-навигатор развития сотрудника.** Employee-first MVP с закрытым профилем, карьерной лестницей, заданиями, Coins и отдельным HR-контуром.

## 1. Название проекта

Рабочее название решения — `Career Quest`.

## 2. Краткое описание

Career Quest превращает развитие сотрудника в понятный маршрут: личный профиль → карьерная лестница → персональные задания и курсы → Coins и достижения → следующий уровень. Сотрудник видит только свой кабинет; HR получает отдельный контур для анализа индивидуальных и командных рисков.

## 3. Что реализовано

Реализованы демо-вход по коду сотрудника, личный кабинет в Halyk-inspired стиле, карьерная лестница, прогресс, Coins, достижения, персональные рекомендации и выполнение активностей. HR-сводка сохранена отдельным API-контуром и не показывается сотруднику в основном интерфейсе.

## 4. Как работает решение

Сценарий сотрудника: ввести код → открыть личный кабинет → увидеть текущую роль и следующий уровень → выбрать рекомендованный курс или задание → выполнить его → получить Coins и обновлённый прогресс. Рекомендации строятся по навыкам, истории и карьерной цели, а причины видны сотруднику.

## 5. Технологии

Для ведения проекта используются Git, GitHub и AI-агент Codex. MVP написан на Python без внешних зависимостей: стандартный HTTP-сервер, HTML/CSS/JavaScript и синтетический датасет. AI-модель не обязательна для запуска: рекомендации и объяснения причин работают детерминированно.

## 6. Архитектура проекта

В репозитории находятся:

- `README.md` — описание текущего состояния проекта.
- `.gitignore` — исключения для локальных секретов и генерируемых файлов.
- `app/data_loader.py` — загрузка и проверка JSON/CSV.
- `app/recommendations.py` — цели, gaps, фильтры и ranking рекомендаций.
- `data/career_quest_dataset/` — синтетический стартовый датасет.
- `app/service.py` — состояние сценария сотрудника и HR-сводка.
- `app/server.py` — локальный HTTP API и раздача интерфейса.
- `app/static/` — employee-first интерфейс с входом, карьерным маршрутом, Coins и заданиями.
- `scripts/build_static.py` — сборка автономной демонстрационной версии для публикации.
- `tests/` — проверки загрузки, recommendation engine и сценария выполнения активности.
- `scripts/demo_recommendations.py` — воспроизводимый пример для трёх профилей.

Подробный анализ кейса находится в [анализе кейса](docs/case-1-analysis.md).

## 7. Установка и запуск

Для получения исходников необходимы Git и доступ к приватному репозиторию команды:

```bash
git clone https://github.com/BAITC-Hacks/hack-7f3075b1-nazhmdt.git
cd hack-7f3075b1-nazhmdt
```

Внешние зависимости для текущего MVP не нужны. Из корня репозитория выполните:

```bash
python3 -m unittest discover -s tests -v
python3 scripts/demo_recommendations.py
python3 -m app.server
```

После запуска откройте `http://127.0.0.1:8000`.

Для другого интерфейса/порта: `python3 -m app.server --host 0.0.0.0 --port 8000`. Адрес `127.0.0.1` доступен только пока процесс сервера запущен.

API-ключи нельзя добавлять в репозиторий.

## 8. Как проверить решение

Проверочный сценарий использует профили `E0001`, `E0002` и `E0028`. Тесты проверяют количество и связи данных, выбор цели, расчёт gaps, отсутствие обязательных и уже завершённых активностей в рекомендациях, а также сценарий просмотра профиля и выполнения активности.

## 9. Данные и интеграции

В репозитории используется синтетический датасет Career Quest: 200 профилей, 40 активностей, 60 навыков и 2 743 записи истории. Внешние интеграции пока не подключены.

## 10. Ограничения

- LLM-слой пока не подключён; ядро формирует структурированные основания рекомендации без API-ключа.
- Вход по коду и Coins работают в демонстрационном режиме; постоянная БД и интеграции с HR/банковскими системами не подключены.
- Состояние выполнения активности хранится в памяти процесса и сбрасывается после перезапуска.
